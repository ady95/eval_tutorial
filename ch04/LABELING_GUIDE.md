# 04-3 라벨링 가이드

`ch04/human_labels.csv`의 `label` 칸에 답변마다 **PASS** 또는 **FAIL**을 적습니다.
판단은 `reference`(정답)를 기준으로 하되, 정답에 적힌 사실을 넘어서는 부분은 여러분의 지식으로 판단합니다.

## 판정 기준

| 판정 | 조건 |
|---|---|
| PASS | 질문이 요구한 내용을 정답과 같은 사실로 답했다. 표현, 말투, 띄어쓰기, 길이의 차이는 무시한다 |
| FAIL | 사실과 다른 내용이 하나라도 있다 (정답에 없는 부연 설명이라도 틀렸으면 FAIL) |
| FAIL | 질문이 요구한 내용이 빠졌다 |
| FAIL | 답변 안에서 서로 모순되는 말을 한다 |

## 애매할 때

- 기준으로 결정하기 어려운 답변이 반드시 나옵니다. 그때는 **여러분이 사용자라면 이 답변을 받아들이겠는가**로 판단하세요.
- 애매했던 답변은 `memo` 칸에 이유를 짧게 적어 두세요. 예: "숫자는 근사값이라 허용", "이름 오타지만 누구인지 알 수 있음"
- 한 번 정한 원칙은 끝까지 같게 적용합니다. 중간에 원칙을 바꿨다면 앞의 답변도 다시 봅니다.
