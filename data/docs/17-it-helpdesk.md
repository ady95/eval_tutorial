# IT 헬프데스크 이용 안내

- 문서 번호: IT-002
- 담당 부서: IT지원팀
- 시행일: 2026년 1월 1일

> 이 문서는 책 「LLM·RAG·에이전트 평가 따라하기」의 실습을 위해 만든 가상 회사 누리솔의 사내 규정입니다. 실존 기업이나 실제 법령과 관계없습니다.

## 1. 운영 시간
- IT 헬프데스크는 평일 09:00~18:00에 운영한다. 점심시간(12:00~13:00)에도 1명이 상주한다.
- 서비스 전체가 멈추는 긴급 장애는 24시간 핫라인(내선 9999)으로 연락한다.

## 2. 요청 방법
- 일반 요청은 사내 포털의 '누리데스크'에서 티켓을 등록한다. 전화는 내선 1234이다.
- 티켓에는 증상, 발생 시각, 화면 캡처를 함께 적는다.

## 3. 처리 기준
- 긴급(업무 중단): 30분 이내 착수
- 높음(일부 기능 불가): 4시간 이내 착수
- 보통(불편하지만 업무 가능): 2영업일 이내 착수

## 4. 소프트웨어 설치
- 회사가 승인한 소프트웨어 목록에 있는 프로그램은 누리데스크에서 직접 설치할 수 있다.
- 목록에 없는 소프트웨어는 티켓으로 요청하면 보안팀 검토를 거쳐 설치 여부를 알려 준다. 검토는 보통 5영업일이 걸린다.
