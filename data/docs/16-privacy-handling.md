# 개인정보 처리 지침

- 문서 번호: SEC-003
- 담당 부서: 보안팀
- 시행일: 2026년 1월 1일

> 이 문서는 책 「LLM·RAG·에이전트 평가 따라하기」의 실습을 위해 만든 가상 회사 누리솔의 사내 규정입니다. 실존 기업이나 실제 법령과 관계없습니다.

## 1. 접근 권한
- 고객 개인정보는 업무상 필요한 직원만 볼 수 있으며, 접근 권한은 팀장 신청과 보안팀 승인으로 부여한다.
- 부서를 옮기거나 퇴직하면 접근 권한을 즉시 회수한다.

## 2. 다운로드와 출력
- 고객 개인정보를 개인 PC에 내려받을 수 없다. 꼭 필요하면 보안팀 승인을 받아 마스킹한 파일만 내려받는다.
- 개인정보가 담긴 문서는 출력하지 않는 것을 원칙으로 하며, 출력한 경우 사용 후 바로 파쇄한다.

## 3. 보관과 파기
- 고객 개인정보는 계약 종료 후 5년 동안 보관한 뒤 파기한다.
- 파기할 때는 복구할 수 없는 방법으로 지우고, 파기 기록을 남긴다.

## 4. 유출 대응
- 개인정보 유출을 알게 되면 즉시 보안팀과 개인정보 보호책임자에게 알린다.
- 회사는 유출 사실을 안 날로부터 72시간 이내에 관계 기관에 신고한다.
