# 비밀번호 정책

- 문서 번호: SEC-002
- 담당 부서: 보안팀
- 시행일: 2026년 1월 1일

> 이 문서는 책 「LLM·RAG·에이전트 평가 따라하기」의 실습을 위해 만든 가상 회사 누리솔의 사내 규정입니다. 실존 기업이나 실제 법령과 관계없습니다.

## 1. 비밀번호 규칙
- 비밀번호는 12자 이상이며 영문 대문자, 소문자, 숫자, 특수문자를 모두 포함해야 한다.
- 아이디, 이름, 생일, 전화번호가 들어간 비밀번호는 쓸 수 없다.

## 2. 변경 주기
- 비밀번호는 90일마다 바꾼다. 만료 14일 전부터 변경 안내 메일을 보낸다.
- 최근에 쓴 비밀번호 5개는 다시 쓸 수 없다.

## 3. 로그인 실패
- 비밀번호를 5회 연속으로 틀리면 계정이 30분 동안 잠긴다.
- 잠긴 계정을 바로 풀려면 IT 헬프데스크에 본인 확인을 거쳐 요청한다.

## 4. 다단계 인증
- 사외에서 사내 시스템에 접속할 때는 다단계 인증(OTP)을 반드시 사용한다.
- OTP 기기를 분실하면 IT 헬프데스크에 바로 신고한다.
